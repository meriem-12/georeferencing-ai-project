
# Datasets

This folder contains the datasets used to evaluate UAV image georeferencing methods.

## Planned Datasets

- UAV-VisLoc
- AnyVisLoc
- University-1652
- VDUAV

## Data Organization

Each dataset should contain the required images, reference imagery, and available metadata.

When available, ground-truth geographic coordinates will be used to evaluate georeferencing accuracy.

## Notes

- Record the source and reference of each dataset.
- Document the coordinate reference system (CRS).
- Keep dataset-specific instructions and licenses.
- Large image files may be stored separately from the GitHub repository.
