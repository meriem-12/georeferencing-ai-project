
# Metrics

This folder contains the evaluation metrics used to assess and compare UAV georeferencing methods.

## Planned Metrics

### Matching Performance
- Number of feature matches
- Number of homography inliers
- Inlier ratio

### Geometric Accuracy
- Reprojection error (pixels)
- Georeferencing error (meters)
- Root Mean Square Error (RMSE), when ground-truth coordinates are available

### Computational Performance
- Execution time (seconds)
- Memory usage, when available

## Results

Experimental results and comparison tables will be generated from the evaluation scripts.

## Notes

- Use the same evaluation protocol when comparing methods.
- Record the dataset and configuration used for each experiment.
- Distinguish image-matching metrics from actual geographic accuracy.
